Student Grade Tracker
📌 Project Overview

Student Grade Tracker is a Java-based console application used to manage and analyze student grades.

The program allows the user to enter student names and their grades. It calculates the average, highest, and lowest scores and displays a summary report of all students.

This project is developed as part of a Java programming task.
🎯 Objectives
Add and manage student grades.
Store student information using ArrayList.
Calculate the average grade.
Find the highest grade.
Find the lowest grade.
Display a summary report.
Provide a simple console-based interface.
🛠️ Technologies Used
Programming Language: Java
Data Structure: ArrayList
Interface: Console
IDE: Visual Studio Code
JDK: Java 17 or later
